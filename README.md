## 🔐 Featured: Security & DevSecOps Projects

> _These repos reflect real-world patterns from enterprise security automation and cloud security posture work._

### 🤖 [AI-Powered Vulnerability Remediation Pipeline](https://github.com/soodrajesh/mcp-ecs-s3-api-poc)
**The problem it solves:** Wiz surfaces hundreds of findings. Manual triage and Terraform fix generation is slow and error-prone.

**What it does:** EventBridge captures Wiz findings → Lambda enriches with context → Bedrock (Claude) generates validated Terraform fixes → PR raised automatically.

**Stack:** `AWS Bedrock` `Claude` `EventBridge` `Lambda` `Wiz API` `Terraform` `Python`

**Outcome:** 60% reduction in mean remediation time at Workday.

---

### 🏛️ [Secure Multi-Tenant ML Platform on EKS](https://github.com/soodrajesh/my-cloud-ai-demo)
**The problem it solves:** Data science teams need GPU workloads with proper IAM scoping and network isolation — without owning infra.

**What it does:** EKS cluster with namespace-level RBAC, IAM roles for service accounts (IRSA), SageMaker integration, and a self-service Terraform module for squad onboarding.

**Stack:** `AWS EKS` `SageMaker` `IRSA` `Terraform` `GitHub Actions` `Docker` `Python`

---

### 🔄 [Enterprise GitOps with Zero-Trust RBAC (ArgoCD)](https://github.com/soodrajesh/argocd-setup)
**The problem it solves:** Multi-squad GitOps with no guardrails leads to blast radius incidents.

**What it does:** ArgoCD with OIDC SSO, namespace-scoped RBAC, multi-tenant app-of-apps pattern, and TLS enforcement — production governance for Kubernetes at scale.

**Stack:** `ArgoCD` `Kubernetes` `OIDC` `RBAC` `Prometheus` `TLS` `Helm`

---

### 📡 [Enterprise RAG Architecture on AWS](https://github.com/soodrajesh/mcp-ecs-s3-api-poc)
**What it does:** MCP server for document summarization via Claude/Bedrock — ECS Fargate, Lambda, API Gateway, S3 — fully Terraformed with IAM scoping and multi-region patterns.

**Stack:** `AWS ECS` `Bedrock` `Lambda` `API Gateway` `S3` `Terraform` `Docker` `Python`

### 📊 [SRE Reliability Framework — Kubernetes](https://github.com/soodrajesh/k8s-grafana-prometheus)
